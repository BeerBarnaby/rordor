# ระยะ B — อ่านรู้เรื่องก่อน เพิ่มลูกเล่นทีหลัง

4 ตุลาคม 2026

## การตรวจเนื้อหา

ผู้ดูแลโครงการแจ้งในแชตว่าครูฝึกตรวจเนื้อหาและให้ผ่านแล้ว บันทึกสถานะใน `src/data/contentReview.ts` อ้าง baseline `238b237` วันที่นี้เป็นวันที่ได้รับแจ้ง ไม่ใช่การเดาวันที่ครูฝึกตรวจ ไม่ระบุชื่อผู้ตรวจเพราะยังไม่ได้รับข้อมูล และไม่ขยายเป็นการรับรองจากหน่วยงานแพทย์หรือใบรับรองทักษะผู้เรียน

รอบนี้ไม่แก้สาระทางการแพทย์/ขั้นตอนช่วยเหลือ หากแก้ในอนาคตต้องตรวจใหม่

## เปลี่ยนแล้วและเหตุผล

- บทเรียน: สิ่งที่ต้องจำและลำดับเดิมมาก่อนวิดีโอ เพื่อให้ทบทวนได้โดยไม่ต้องเลื่อนผ่านคลิป
- เห็นคลิปหลักหนึ่งรายการ คลิปอื่นยังอยู่ครบในดูเพิ่มเติม ลดภาพหลายสไตล์แข่งกันและไม่ทิ้งคลิปทหาร
- แท็บมือถือใช้ชื่อ ประเมิน/แจ้งเหตุ/CPR/AED มี accessible name เต็ม และคง arrow/Home/End keyboard controls
- การ์ดบทเรียนใช้พื้นกลาง สีหมวดไม่แข่งกับสีสถานะ เลขบทไม่ใช่จุดนำในการเลือก
- บันทึกว่าอ่านแล้วเป็นปุ่มรอง เริ่มฝึกเป็นปุ่มหลัก ไม่เรียกการกดอ่านจบว่า “ผ่าน”
- หน้าแรกหัวข้อสั้น ลด rail รายการ4ขั้นที่ซ้ำความคืบหน้า และลูกศรที่ทำให้รายการไม่กดดูเหมือนกดได้
- บอก guest ใช้งานได้ บอกตรงว่าการรีเฟรชยังไม่รองรับ mission resume แทนคำว่า “บันทึกไว้”
- แก้ undefined color token ของ video context label

## ยังไม่รวม

Draft persistence, online scoring versions, XP ledger และ deep links อยู่ระยะ C/D ไม่ใช่สิ่งที่การอนุมัติเนื้อหาทำให้เสร็จโดยอัตโนมัติ
