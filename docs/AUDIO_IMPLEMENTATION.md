# ระบบเสียงฝึก (ไม่เปลี่ยนดีไซน์เดิม)

## วิธีใช้

1. กดรูปลำโพงที่หัวเว็บเพื่อเปิดหรือปิดเสียง ค่าเริ่มต้นปิด
2. ขณะตรวจคำตอบลำดับช่วยเหลือและแจ้งเหตุ จะมีเสียงสั้นแยกคำตอบถูกกับคำตอบที่ต้องทบทวน
3. ในหน้า CPR เปิดปุ่ม “เสียงนำจังหวะ 110 ครั้ง/นาที” ได้แยกต่างหาก
4. เมื่อออกจากหน้า CPR ซ่อนแท็บ หรือจบการกด เสียงนำจังหวะจะหยุด
5. ผลฝึกระบุว่ารอบนั้นใช้เสียงนำจังหวะ ไม่เปลี่ยนสูตรคะแนนหรือเพิ่ม XP จากการเปิดเสียง

## เหตุผลในการออกแบบ

- เสียงเป็นตัวช่วย ไม่เป็นเงื่อนไขการใช้งาน ทุกข้อความและขั้นตอนยังอ่านได้เมื่อปิดเสียง
- ไม่เล่นอัตโนมัติเมื่อเปิดเว็บ แม้จำค่าการเปิดเสียงไว้ ต้องมีการกดของผู้ใช้ก่อนเริ่มระบบเสียง
- ใช้เสียงสั้นเบา ไม่มีเพลงพื้นหลัง เพื่อไม่แย่งความสนใจจากข้อความสำคัญ
- ขั้น AED มีเพียงเสียงตอบรับการกด ไม่เลียนแบบเสียงเตือนหรือคำสั่งของเครื่อง AED จริง
- เสียงนำจังหวะเป็นการฝึกแบบมีตัวช่วย ไม่ใช่การประเมินทักษะ CPR ภาคปฏิบัติ

## การไหลของข้อมูล

`SoundToggle → setSoundEnabled → localStorage / ค่าในเซสชัน → training-sound → ส่วนประกอบ UI`

`การกดตอบ → playCue → AudioContext → oscillator + gain → ลำโพง`

`CPR compressing + เปิดเสียง + เปิดตัวช่วย + หน้าฝึกใช้งานอยู่ + แท็บมองเห็น → metronome scheduler`

`ใช้ตัวช่วย CPR → cprAudioGuided → MissionResult → ข้อความในสรุปผล`

ไม่มีการอัดเสียง ไม่ขอสิทธิ์ไมโครโฟน ไม่ส่งข้อมูลเสียงออกไปภายนอก และไม่เพิ่มไฟล์เสียงที่ต้องดาวน์โหลด

## การดูแลและข้อจำกัด

- ตัวสร้างเสียงอยู่ที่ `src/lib/trainingAudio.ts` เปลี่ยนความดังผ่าน master gain และความถี่ผ่าน cueFrequencies
- ความเร็วเสียงนำจังหวะกำหนดโดย METRONOME_BPM; การวัดจังหวะยังใช้การแตะจริง ไม่ใช้จำนวนเสียงที่เล่น
- Web Audio ตั้งเวลาเสียงล่วงหน้าระยะสั้น ลดความคลาดเคลื่อนจากการแสดงผล UI; ไม่รับประกันความแม่นยำระดับอุปกรณ์แพทย์
- การปิดเสียงตัดความดังทันที การหยุดตัวช่วยยกเลิกตัวตั้งเวลา อาจเหลือเสียงที่ตั้งไว้ก่อนหน้าไม่เกินประมาณ 140 มิลลิวินาที
- เบราว์เซอร์ที่ไม่รองรับยังฝึกแบบเงียบได้ ถ้าบันทึกค่าลงเครื่องไม่ได้จะใช้เฉพาะเซสชัน
- ตรวจด้วยชุดทดสอบและเบราว์เซอร์บนเครื่องพัฒนาแล้ว ยังต้องลองความดังและพฤติกรรมเสียงบน iPhone/iPad และ Android จริงก่อนยืนยันการรองรับอุปกรณ์ทุกชนิด
