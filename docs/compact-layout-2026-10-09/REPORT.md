# หน้าแรกและหน้าเลือกภารกิจฉบับกระชับ

9 ตุลาคม 2026 — ฉบับในเครื่อง ผู้ใช้อนุญาตคอมมิทแล้ว ยังไม่ push/deploy รอบนี้

## แก้ปัญหาจากภาพที่ผู้ใช้ส่ง

หน้าเลือกภารกิจเดิมใช้ page-stack กับข้อความแต่ละชิ้น จึงได้ gap ระดับหมวด 32px ซ้ำหลายครั้ง กลายเป็นย่อหน้ายาว ภารกิจเสริมและปุ่มถูกดันพ้นจอ เปลี่ยนเป็น MissionMenu ที่ใช้การ์ดละ gap12px ภาพประกอบ ชื่อภารกิจ และปุ่มอยู่ในขอบเขตเดียวกัน ชื่อหน้า «เลือกภารกิจ» ไม่ซ้ำข้อความยาว ภารกิจหลักใช้ปุ่มแดง AED เป็นตัวเลือกเสริมปุ่มรอง ไม่เปลี่ยนคะแนนหรือเนื้อหาการรักษา

หน้าแรกคง headline สี ตัวละครและฟอนต์ที่เลือกไว้ แต่ลด padding/type scale เฉพาะมือถือ ปุ่มยังสูงอย่างน้อย48px ย่อข้อความคู่ตัวละครเหลือหนึ่งประโยค รูป object-contain สูง115px ไม่ครอป และไม่ดันภาพลงท้าย card สูง ๆ

## ตรวจ

- 57 tests, lint, build ผ่าน ใช้ React Best Practices ตรวจ component boundaries; callback ของ MissionMenu อยู่ใน client tree เดิม
- 390×844: ปุ่มหลักจบ y447, AEDจบ y733 ก่อน nav y770 ทั้งสองอยู่ในจอแรก; ภาพตัวละครหน้าแรกจบ y556 และ heroจบ y576 ก่อน nav y770
- 320×740: ไม่มี overflow แนวนอน ภาพหน้าแรกจบประมาณy589 ก่อนnavy666 หน้าเลือกภารกิจเลื่อนดูปุ่ม AEDได้ ไม่อ้างว่าทั้งหน้าอยู่เหนือ fold บนจอเล็กนี้
- 768×1024 และ1440×900: การ์ดเป็นสองคอลัมน์ ปุ่มแนวเดียวกัน ไม่ล้นแนวนอน
- ปุ่มหลักเปิด opening ของภารกิจเดิม พักแล้วกลับเมนูแสดง «ฝึกภารกิจหลักต่อ»; ปุ่ม AEDเปิดโหมดเสริมโดยตรง
- ไม่เล่นภารกิจจนจบในรอบตรวจ layout นี้ ไม่เพิ่มผล/XP ยกเลิกเฉพาะกิจกรรมทดลองในหน้านี้ด้วย reload ไม่ล้าง storage
- ภาพหลักฐานเก็บในโฟลเดอร์นี้ เปิดดูไฟล์ที่บันทึกแล้ว ไม่ใช่ mockup หรือ screenshot ของเวอร์ชันเก่า

การตรวจ viewport ไม่ใช่การตรวจบนอุปกรณ์จริง และไม่ได้อ้าง WCAG compliance
