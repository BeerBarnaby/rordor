## สิ่งที่เปลี่ยนและเหตุผล

1. บทเรียน: ภาพแยกตามหัวข้อพร้อมชื่อและปุ่มเปิดชัดเจน ทุกบทเปิดให้เรียน AED อยู่แยกเป็นเสริม บทละเอียดเรียงเป้าหมาย → ขั้นตอนสำคัญ → วิดีโอ → แหล่งอ้างอิง → บันทึกทบทวน เปลี่ยนแท็บตัวเลขล้วนเป็นชื่อย่อที่อ่านออกบนมือถือ พร้อมชื่อเต็มสำหรับเครื่องอ่านหน้าจอ
2. จัดลำดับ: ตัวเลือกใช้ชื่อขั้นตอนอย่างเดียว ไม่ซ้ำคำอธิบายทุกการ์ด แสดงเลือกแล้วกี่ข้อ เปิด «ลำดับของคุณ» เพื่อสลับ/นำออกได้ รายละเอียดเดิมกลับมาเมื่อเฉลย เลือกได้สูงสุดเท่าจำนวนข้อที่โจทย์ต้องการ ปุ่มที่ยังเลือกไม่ครบไม่ลอยทับตัวเลือก
3. 1669: แยกสายจำลอง ความคืบหน้า คำถามเจ้าหน้าที่ และคำตอบผู้เรียนเป็นส่วนคนละฝั่ง ไม่เล่นเสียงคำถามหรือโทรจริง เก็บบทสนทนาก่อนหน้าไว้เปิดอ่าน เมื่อแก้คำตอบยังคงคะแนนครั้งแรกเหมือนเดิม เมื่อไปคำถามใหม่เลื่อนกลับต้นหน้าจอ
4. CPR: ตอนเตรียมใช้ภาพปกและเป้าหมายชัดเจน ตอนแตะไม่มีภาพตกแต่งหรือหัวใจ พื้นฝึก navy ปุ่มแดง «แตะ» ตัวเลขจังหวะเด่น ปุ่มเสียงเก็บในส่วนเปิดอ่านได้ ไม่เพิ่มการกะพริบหรือจังหวะภาพที่อาจนำผิด การเปลี่ยนขั้นกลับต้นหน้าจอ
5. สรุป: นำ «ฝึกต่อเรื่องนี้ก่อน» ขึ้นก่อนคะแนน ใช้คะแนนแต่ละส่วนและ threshold เดิมเพื่อแนะนำบท ไม่เปลี่ยนสูตรคะแนน ปุ่มเปิดบทที่แนะนำตรง ๆ ลดคะแนนซ้ำสองชุด ย่อรายการทบทวนและเปิดดูที่เหลือได้ แก้คำชม AED ที่อ้างผิดเมื่อผลภารกิจหลักไม่มี AED

## การตรวจในเบราว์เซอร์

เล่นภารกิจหลักครบโดยไม่ล็อกอิน จัดลำดับถูก 7/7 หลังทดสอบขึ้น/ลงและนำออก/เพิ่มกลับ เลือกข้อมูล 1669 ที่ขาดข้อมูลหนึ่งข้อแล้วแก้ครบ: สรุปยังแจ้งครบตั้งแต่ครั้งแรก 5/6 และคะแนน 92% ไม่กลายเป็น 100%

CPR ทดสอบปุ่มผ่าน keyboard 30 ครั้งอย่างรวดเร็วเพื่อยืนยันการเปลี่ยนขั้น ไม่ใช้เป็นการวัดจังหวะหรือความสามารถจริง ได้จังหวะ 0% และคะแนนรวม 64% ตรงสูตรเดิม (100+92+0)/3 หน้าสรุปไม่อ้างฝึก AED และปุ่มแนะนำเปิดบท CPR ได้จริง ผลทดลองหนึ่งครั้งถูกเก็บในเบราว์เซอร์นี้ตามพฤติกรรมแอปเดิม ไม่มีการส่งคะแนนสูตรใหม่ขึ้นอันดับออนไลน์

ภาพหลักฐานรอบนี้อยู่ใน docs ชื่อ `lessons-refresh-*`, `sequence-refresh-*`, `call-question-refresh-*`, `call-reply-refresh-*`, `cpr-refresh-*`, `review-refresh-*` รูปก่อนการแก้ spacing รอบสุดท้ายไม่ใช้ยืนยันรายละเอียด spacing ของฉบับสุดท้าย

ข้อจำกัด: ไม่ใช่การทดสอบบนอุปกรณ์จริง ไม่ตรวจเสียงจริงหรือรับรอง WCAG ไม่เปลี่ยนเนื้อหาทางการแพทย์เดิม ภาพปกใหม่เป็นสื่อประกอบควรให้ครูฝึกตรวจอีกครั้งก่อนเผยแพร่
