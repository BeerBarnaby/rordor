# ลูกเล่นและโมชั่นฉบับลอง

เพิ่มเฉพาะการตอบสนองสั้น ๆ ไม่เปลี่ยนสีหลัก รูปแบบหน้า คะแนน XP หรือระบบเสียง

- ภาพหน้าแรกเข้ามาครั้งเดียว ไม่ลอยหรือขยับวน
- การ์ดบทเรียนทยอยเข้ามา 280ms เว้น 55ms; hover เฉพาะอุปกรณ์ที่มี pointer แบบละเอียด ภาพขยายเล็กน้อยและมี focus ring สำหรับคีย์บอร์ด
- เพิ่มขั้นตอน: ตัวเลขเลือกแล้วและการ์ดที่เพิ่มตอบสนอง 180ms; ปุ่มตรวจคำตอบเน้นหนึ่งครั้งเมื่อเลือกครบ
- 1669: คำถามเข้าเมื่อเปลี่ยน field และคำตอบเข้าเมื่อเลือก ไม่เพิ่ม typing delay ไม่ซ่อนคำถามเพื่อรอ animation และไม่เปลี่ยนคะแนนครั้งแรก
- ผลสรุป: ข้อเสนอฝึกต่อและแถบคะแนนเปิดเผยค่าจริง ไม่ทำคะแนนวิ่งหรือสุ่มรางวัล
- ตอน CPR ไม่มี animation นำจังหวะใหม่ ไม่มีภาพกระพริบ; marker ขั้นตอนจาก pulse วนเปลี่ยนเป็น one-shot เพื่อไม่ปะปนกับจังหวะฝึก

ใช้ CSS transform/opacity เป็นหลัก ไม่มี library หรือ assets ใหม่ Motion อยู่ภายใน prefers-reduced-motion: no-preference และกฎลด motion เดิมยังปิด animation/transition ทั้งหมด ไม่มีการเปลี่ยน localStorage หรือค่าคะแนนเพื่อแต่งภาพ

ฉบับนี้ให้ลองในเครื่องก่อน ผู้ใช้อนุญาตคอมมิทเมื่อ 9 ตุลาคม 2026 ยังไม่ push หรือ deploy รอบนี้

ตรวจแล้ว: tests 57 รายการ, lint และ build ผ่าน ใน browser การ์ดใช้ ready-card-in 280ms พร้อม stagger 0/55/110ms; ตัวเลขเลือกแล้วและปุ่มใช้ selection-ack/action-ready; คำถามกับคำตอบใช้ conversation-in/reply-in ตรวจตัวเลือกและการต่อไป 1669 ยังทำงาน คะแนนลำดับ 7/7 เหมือนเดิม ทดสอบหยุดก่อนจบภารกิจเพื่อไม่เพิ่มผลหรือ XP อีกครั้ง

จำลอง prefers-reduced-motion: reduce ด้วยเครื่องมือ browser แล้วตรวจว่าการ์ดทุกใบ animation = none จากนั้นยกเลิกการจำลองและคืน viewport ปกติ ไม่เปลี่ยนการตั้งค่าระบบของผู้ใช้ ไม่มี error/warn ใน browser logs ที่ตรวจ ภาพนิ่ง docs/motion-lessons-trial.png ใช้ยืนยัน layout เท่านั้น ไม่ใช่หลักฐานจังหวะเคลื่อนไหวจริง เปิด localhost เพื่อทดลอง motion
