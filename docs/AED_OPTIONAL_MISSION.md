# ภารกิจ AED แบบเลือกฝึก

8 ตุลาคม 2026

## ทางเข้า

- เมนูฝึกสถานการณ์ → เลือกภารกิจหลัก หรือภารกิจเสริม AED
- บทเรียน AED → ทบทวน AED ทีละขั้น
- หน้าแรกยังเริ่มหรือฝึกภารกิจหลักต่อโดยตรง

## เส้นทาง

ภารกิจหลัก: จัดลำดับช่วยเหลือ → แจ้งเหตุ 1669 → CPR → สรุปผล

ภารกิจเสริม: เปิด AED → ติดแผ่น → เคลียร์พื้นที่ → วิเคราะห์ → ช็อก/ไม่ช็อก → CPR → จบภารกิจเสริม → ฝึกอีกผลวิเคราะห์ หรือกลับหน้าเลือกภารกิจ

## ข้อมูลและข้อจำกัด

ภารกิจ AED เก็บสถานะในหน่วยความจำเท่านั้น ไม่เพิ่ม XP ไม่ส่งลีดเดอร์บอร์ด ไม่บันทึกผลภารกิจหลัก การออกจากภารกิจ AED จะเริ่มใหม่เมื่อเข้าครั้งถัดไป ภารกิจหลักที่พักไว้ยังอยู่ใน session เดิม แต่รีโหลดจะไม่รับประกันการกลับสู่ขั้นที่ค้างไว้

การแยกภารกิจเป็นลำดับการเรียนรู้ ไม่ใช่คำแนะนำให้ละเลย AED ในเหตุจริง เนื้อหาเกี่ยวกับการเรียกหาและใช้ AED ในบทเรียนและลำดับช่วยเหลือยังคงเดิม
