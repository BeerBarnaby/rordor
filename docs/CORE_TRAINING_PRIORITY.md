# เส้นทางหลัก CPR และการแจ้งเหตุ

6 ตุลาคม 2026 ตามคำขอผู้ดูแล: ให้ AED เป็นเนื้อหาเสริม ไม่บังคับในการจบภารกิจ

เส้นทางหลัก: ประเมิน/จัดลำดับ → จำลองโทร 1669 → ฝึกจังหวะ CPR → สรุปผล

เมื่อจบ CPR สร้างผลจากค่าที่ callback ส่งเข้ามาโดยตรง ไม่อ่านค่า CPR ที่เพิ่งสั่ง setState เพื่อป้องกันคะแนนเก่าหรือ 0 จาก state ที่ยังไม่อัปเดต สูตรยังเฉลี่ยสามแบบฝึกตามเดิม ไม่เพิ่มคะแนน AED ในผลใหม่ และไม่แก้ประวัติภารกิจเก่า

หน้าแรกแสดง 3 ขั้น หน้าบทเรียนมี 3 บทหลัก และ AED แยกในส่วน “เรียนเพิ่มเติมเมื่อสนใจ” ทุกบทเปิดให้เรียน ไม่มีการล็อกหรือบังคับเข้าสู่ระบบ โหมด AED ทีละขั้นและสองผลวิเคราะห์ยังอยู่ และไม่เพิ่ม XP จากการทบทวนตามเดิม

นี่เป็นการจัดลำดับการเรียนในผลิตภัณฑ์ ไม่ใช่คำแนะนำให้งด AED ในเหตุจริง เนื้อหาการขอ AED ในลำดับช่วยเหลือยังคงไว้

ผลหลักที่ไม่ได้ผ่าน AED จะแสดงว่า AED เป็นบทเรียนเสริม ไม่อ้างว่าทบทวนครบ ผลเก่าที่มี aedRecommendation ยังคงแสดงผลเดิมได้
