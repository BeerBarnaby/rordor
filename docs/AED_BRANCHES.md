# ผลเครื่อง AED จำลองสองกรณี

## สถานะล่าสุด — 8 ตุลาคม 2026

AED เป็นภารกิจเสริมแยกในหน้า «ฝึกสถานการณ์» และเปิดได้จากบทเรียนด้วย ไม่บังคับทำเพื่อจบภารกิจหลัก ไม่เพิ่ม XP ไม่บันทึกคะแนนหรือประวัติภารกิจหลัก เนื้อหา AED ในลำดับช่วยเหลือยังคงอยู่

ภารกิจเสริมเริ่มด้วยผลแนะนำให้ช็อก เมื่อจบสามารถกด «ฝึกอีกผลวิเคราะห์» เพื่อฝึกกรณีไม่แนะนำให้ช็อก สลับได้ในรอบฝึกนี้เท่านั้น ไม่สลับจากจำนวนภารกิจหลักอีกแล้ว ผู้เรียนไม่ได้ตัดสินผลวิเคราะห์เอง และไม่สามารถข้ามช่วงวิเคราะห์ได้

รายละเอียดด้านล่างเป็นประวัติการพัฒนาก่อนแยกภารกิจ ไม่ใช่พฤติกรรมปัจจุบัน

6 ตุลาคม 2026

โค้ดเดิมรองรับทั้ง shock และ no-shock อยู่แล้ว รอบนี้เปลี่ยนตัวเลือกผลจากตัวนับใน session เป็นจำนวนภารกิจที่จบและบันทึกไว้ในเครื่อง ผ่าน `recommendationForNextPractice` จากนั้นเก็บผลไว้ใน state ตอนเริ่มภารกิจ ไม่เปลี่ยนผลกลางภารกิจหากข้อมูลความคืบหน้าเปลี่ยน

- จำนวนภารกิจที่จบเป็นเลขคู่: ครั้งใหม่จำลองแนะนำให้ช็อก
- จำนวนภารกิจที่จบเป็นเลขคี่: ครั้งใหม่จำลองไม่แนะนำให้ช็อก
- การออกก่อนจบหรือรีโหลดไม่ถือว่าฝึกจบ จึงไม่บังคับสลับผล
- เมื่อจบและเปิดเว็บใหม่ ครั้งถัดไปยังสลับตามความคืบหน้าที่เก็บไว้ หากล้างข้อมูลหรือใช้โหมดที่เก็บข้อมูลไม่ได้ จะไม่รับประกันการสลับข้ามการเปิดเว็บ

ผู้เรียนไม่ได้เลือกว่าผู้ป่วยควรถูกช็อกหรือไม่ ผลเป็นโจทย์ของเครื่องจำลองและแสดงเมื่อวิเคราะห์เสร็จเท่านั้น ปุ่ม continue ไม่ข้าม analyzing ทั้งสองกรณีไป resume → complete และผลการฝึกบันทึก aedRecommendation ตามเดิม ไม่เพิ่มคะแนนทักษะ AED หรือเปลี่ยน XP

เพิ่มคำเตือนในหน้า no-shock ว่าไม่แนะนำให้ช็อกไม่ได้หมายความว่าผู้ป่วยฟื้นแล้ว และให้กลับไปทำ CPR ต่อ สอดคล้องกับ [American Red Cross: AED Steps](https://www.redcross.org/take-a-class/aed/using-an-aed/aed-steps) ที่ระบุให้เริ่ม CPR ทันทีหลังช็อกหรือเมื่อไม่แนะนำให้ช็อก เนื้อหายังเป็นสื่อเสริมและควรให้ครูฝึกตรวจการใช้จริง

ทดสอบ state machine เดิมทั้งสองสาขา และเพิ่ม tests การสลับจากข้อมูลที่บันทึก / normalization ของค่าตัวนับ ยังไม่ deploy ในรอบนี้
