## Mobile

Header → สถานการณ์ฝึก → เจอคนหมดสติ / เราจะทำอะไรก่อน? → 4 ขั้น / ~5 นาที → ปุ่มฝึก → เปิดบทเรียน → ข้อจำกัดสั้น → กิจกรรมในรอบนี้

CTA จาก checkpoint เป็น “กลับมาฝึกต่อ”; เมื่อมีรอบใน memory บอกกิจกรรมปัจจุบัน; เมื่อไม่มีรอบไม่แสดงสถานะสำเร็จจากคะแนนเก่าที่ไม่เกี่ยวกัน

“ทำจบแล้ว” หมายถึงจบกิจกรรมก่อนหน้า ไม่ใช่ผ่านทักษะคลินิก ทุกบทเปิดอิสระ และการกดชื่อในรายการหมายถึงเปิดบทเรียน ไม่ใช่ข้ามขั้นภารกิจ

## Typography/สี

คง LINE Seed Sans TH ตามคำขอเดิม ใช้หัวหลัก 700 และคำถามรอง 400 ไม่ใช้แดงแยกคำในหัวข้อ ขนาดมือถือ 28–36px, desktop 38px, line-height 1.35; ข้อความทั่วไปไม่เปลี่ยนเป็นน้ำหนักที่ไม่ได้โหลด

พื้น #FCFAF8; ขาวสำหรับผิวเนื้อหา; สีดำ/เทาสำหรับ navigation/บันทึก; แดงสำหรับ primary action/current step; เขียวสำหรับกิจกรรมที่จบแล้วโดยมีคำกำกับ ไม่ใช้สีอย่างเดียว

## ข้อมูลที่ไม่สร้างขึ้น

ไม่ใส่คะแนนความมั่นใจ/คำพูดครูฝึก/จุดที่มักสับสนโดยไม่มีการวัด ประวัติใช้ผลและวันที่เดิมจริง ไม่คำนวณ “กี่วันที่แล้ว” จากวันที่ไทยที่เป็นข้อความ
