# Dashboard ภาพรวมการฝึก

ปรับปรุงวันที่ 27 ตุลาคม 2569

## วิธีใช้งาน

เข้าสู่ระบบด้วยบัญชีผู้ดูแล แล้วเปิด `/admin` หน้าแรกของหลังบ้านจะเป็น “ภาพรวมการฝึก”

1. เลือกช่วงเวลา 7, 30 หรือ 90 วันล่าสุด รวมวันนี้ตามเวลาไทย
2. กรองตามสถานศึกษาและชั้นปี หรือเลือกบุคคลทั่วไป / อื่น ๆ
3. ดูคะแนนแยกสามด้านและหัวข้อที่มีคะแนนเฉลี่ยต่ำที่สุด เพื่อวางแผนทบทวน
4. ดูจำนวนครั้งที่ฝึกจบรายวัน และเปิด “ดูข้อมูลรายวัน” เพื่ออ่านตัวเลข
5. เปรียบเทียบผลตามสถานศึกษา/ชั้นปี พร้อมจำนวนผู้ฝึกของแต่ละกลุ่ม
6. อ่านค่าเฉลี่ยแบบประเมินและหัวข้อที่ผู้เรียนขอให้ปรับปรุง
7. กด “ส่งออก CSV” เพื่อดาวน์โหลดข้อมูลรวมตามตัวกรอง เปิดใน Excel ได้

เมนูผู้ใช้งาน ผลการฝึก แบบประเมิน และการเข้าสู่ระบบเดิมยังใช้ดูรายละเอียดรายบุคคลได้

## ความหมายของข้อมูล

| ตัวเลข | วิธีคำนวณ |
| --- | --- |
| ผู้ลงทะเบียนในกลุ่ม | บัญชีผู้เรียนทั้งหมดที่ตรงกับสถานศึกษาและชั้นปี ไม่จำกัดวันสมัคร |
| ผู้ฝึกในช่วงนี้ | จำนวนคนไม่ซ้ำที่มีผลการฝึกในช่วงที่เลือก |
| ฝึกจบในช่วงนี้ | จำนวนผลการฝึกทั้งหมดในช่วงนั้น รวมการฝึกซ้ำ |
| คะแนนเฉลี่ยล่าสุด | เลือกผลล่าสุดคนละหนึ่งครั้งภายในช่วงที่เลือก แล้วเฉลี่ยคะแนนรวม |
| คะแนนแยกทักษะ | ใช้ผลล่าสุดชุดเดียวกัน เฉลี่ยลำดับช่วยเหลือ / แจ้งเหตุ / จังหวะ CPR |
| ผลตามสถานศึกษาและชั้นปี | จัดกลุ่มผลล่าสุดตามโปรไฟล์ปัจจุบันของผู้เรียน |
| แบบประเมิน | แบบประเมินล่าสุดต่อคนที่ส่งหรือแก้ไขในช่วงที่เลือก คะแนนเต็ม 5 |

ใช้เฉพาะ `game_attempts_v2` ที่ `audio_guided = false` ไม่รวมคะแนน legacy บัญชีแอดมิน และผล Guest ที่เก็บในเครื่อง
วันที่ใช้ Asia/Bangkok; เมื่อไม่มีข้อมูล คะแนนเป็น `null` และแสดง “—” ไม่แสดงเป็นศูนย์
คำแนะนำเป็นการเลือกทักษะที่มีคะแนนเฉลี่ยต่ำที่สุด ไม่ใช่ข้อสรุปว่าผู้เรียนขาดทักษะทางการแพทย์

## การไหลของข้อมูลและสิทธิ์

`TrainingDashboard → GET /api/player/admin/analytics → adminRpc → public.admin_training_analytics → nong_prom_private.admin_training_analytics`

- API ตรวจ session cookie, server secret และค่าตัวกรอง
- PostgreSQL ตรวจบัญชีแอดมินและวันหมดอายุเซสชันด้วย `require_admin` ก่อนอ่านข้อมูล
- เก็บ secret ไว้ฝั่งเซิร์ฟเวอร์ใน `NONG_PROM_ADMIN_SECRET` เช่นเดียวกับหลังบ้านเดิม
- API ส่งเฉพาะข้อมูลรวมและชื่อสถานศึกษา ไม่ส่ง PIN, token หรือเบอร์โทร
- Response ใช้ `private, no-store`; เปลี่ยนตัวกรองจะยกเลิกคำขอเก่าเพื่อป้องกันผลสลับกัน
- CSV มี UTF-8 BOM และป้องกันสูตรจากชื่อสถานศึกษาที่ผู้ใช้กรอก
- Migration เพิ่ม RPC โดยไม่แก้ตารางข้อมูลเดิมหรือเปิดสิทธิ์อ่านตารางโดยตรง

## การตรวจสอบ

- Unit/API tests ครอบคลุมกรองชั้นปี 0, ค่าผิดรูปแบบ, ไม่มีข้อมูล, คะแนนศูนย์, CSV และการปฏิเสธผู้ไม่มีสิทธิ์
- `supabase/tests/admin_training_analytics.sql` ทดสอบ SQL ด้วยข้อมูลใน transaction และ rollback ทั้งหมด
- ตรวจหน้าตาด้วยข้อมูลตัวอย่างที่ 1280px และ 390px; ตารางกว้างเลื่อนภายในกรอบได้
- `npm test`, `npm run lint`, `npm run build`

## ขอบเขตของรุ่นนี้

ยังไม่มีข้อมูลสำหรับอัตราเริ่มแล้วทำไม่จบ, ข้อคำถามที่ผิดซ้ำ, การจบบทเรียนออนไลน์, คะแนนก่อน–หลังเรียน หรือข้อมูลแรง/ความลึก CPR จึงยังไม่แสดงตัวชี้วัดเหล่านี้
แบบประเมินเป็นค่าล่าสุดที่แก้ไขได้ ไม่ใช่ประวัติแบบประเมินทุกครั้ง
ชื่อสถานศึกษาที่ผู้ใช้พิมพ์ต่างกันจะเป็นคนละกลุ่ม จึงควรเลือกชื่อจากรายการมาตรฐานขณะสมัคร
